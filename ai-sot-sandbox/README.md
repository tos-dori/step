# AI Source of Truth Sandbox

> TEST ONLY — 이 폴더는 GitHub 기반 AI Source of Truth 운영을 검증하기 위한 격리된 실험 공간이다.

- 기존 Step 코드·문서의 공식 원본이 아니다.
- 기존 파일은 수정하지 않는다.
- 이 폴더 안에서만 생성·읽기·수정·삭제를 시험한다.
- 사용자가 삭제를 요청하면 이 폴더의 생성 파일을 제거한다.

## 시험 범위

1. 새 상태 파일 생성
2. 다른 요청에서 같은 파일 재조회
3. 최신 SHA를 기준으로 최소 수정
4. 수정 결과 재조회
5. 임시 파일 생성·삭제
6. 시작 커밋과 종료 커밋 비교
