# Step AI Source of Truth — Sandbox State

> 상태: 실험용 초안
> 공식 원본 여부: 아니오
> 적용 범위: `ai-sot-sandbox/` 내부만

## 목적

여러 ChatGPT 채팅방이 GitHub의 동일한 Markdown 파일을 최신 원본으로 읽고, 사용자의 명시적 승인 아래 필요한 부분만 수정할 수 있는지 검증한다.

## 고정 원칙

- 기존 Step 코드와 문서는 수정하지 않는다.
- 이 문서는 실제 프로젝트 상태를 확정하는 공식 문서가 아니다.
- 확인되지 않은 구현·패치·테스트를 완료로 기록하지 않는다.
- 수정 전 최신 파일과 blob SHA를 다시 확인한다.
- 사용자의 검토 요청을 수정 승인으로 해석하지 않는다.

## 현재 검증 상태

- [x] 격리된 새 폴더 생성
- [x] 안내 파일 생성
- [x] 상태 파일 최초 생성
- [ ] 상태 파일 재조회
- [ ] 최신 SHA 기반 최소 수정
- [ ] 수정 결과 재조회
- [ ] 임시 파일 생성·삭제
- [ ] 전체 diff 검수

- 다른 ChatGPT 채팅방에서도 동일 경로를 안정적으로 찾아 읽는 운영 방식
- Skill 설치·동기화 방식
- 프로젝트별 공식 상태 문서의 최종 위치와 구조
